6D 網址傳送門 · 編輯工具

這頁只有你自己會用到，學生不會看到這個畫面。使用步驟：

  1. 先在下面「GitHub 直接發佈」填好設定（帳號、Repo、Token）
  2. 按「匯入 GitHub 上的最新版本」，確保你是從最新內容開始改，不會蓋掉同事剛更新的東西
  3. 修改標題、科目、連結
  4. 按「直接發佈到 GitHub」一鍵完成。（如果還沒設定 GitHub，也可以用「選擇檔案」匯入本機的舊檔案，或用「下載檔案」自己去 GitHub 手動上傳，但要留意可能不是最新版本）

GitHub 直接發佈（設定一次，之後一鍵發佈）

這裡不是網站的登入功能，而是讓這個編輯工具直接幫你把檔案傳去 GitHub，省掉手動上傳那步。 你需要一組「Personal access token」，作用像密碼，只有你自己拿著：

  1. 在 github.com/settings/tokens → Fine-grained tokens → Generate new token
  2. Repository access 選「Only select repositories」，只勾你這個 repo（例如 6d-link-portal）
  3. Permissions → Contents 設為「Read and write」，其他保持預設
  4. 按 Generate token，複製那組以 github_pat_ 開頭的文字，貼到下面「Token」欄
這樣就算 token 外洩，別人也只能改這一個 repo，改不了你其他東西。
